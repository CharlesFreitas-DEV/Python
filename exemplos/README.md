## 📖 Sobre este documento

Este documento reúne os objetivos dos projetos desenvolvidos em **Python** disponíveis neste repositório.

Cada projeto foi criado com finalidade **didática**, abordando um problema específico e demonstrando conceitos importantes da linguagem Python, da manipulação de arquivos, da automação de tarefas e da integração com ferramentas externas.

O objetivo é disponibilizar exemplos simples, bem documentados e de fácil compreensão para estudantes, professores e desenvolvedores.

---

## 🖼️ EXIF Metadata Reader

### Objetivo

Demonstrar como realizar a leitura manual de metadados **EXIF** armazenados em imagens **JPEG**, interpretando diretamente a estrutura binária do arquivo, sem utilizar bibliotecas especializadas.

O projeto tem como foco o estudo de:

- Manipulação de arquivos binários;
- Estrutura interna do formato JPEG;
- Organização dos metadados EXIF;
- Estrutura TIFF utilizada pelo padrão EXIF;
- Conversão de coordenadas GPS;
- Programação de baixo nível utilizando apenas a biblioteca padrão do Python.

---

## 🎵 MP4 Audio Extract

### Objetivo

Demonstrar como automatizar a extração de áudio de vídeos **MP4** para arquivos **MP3** utilizando **Python** em conjunto com o **FFmpeg**.

O projeto apresenta conceitos como:

- Automação de tarefas;
- Manipulação de arquivos;
- Execução de programas externos;
- Conversão de mídia utilizando FFmpeg;
- Tratamento de erros;
- Desenvolvimento de utilitários simples e portáveis.

## 🎯 Objetivo Geral da Coleção

Esta coleção de projetos tem como propósito apresentar implementações práticas em Python que auxiliem no aprendizado da linguagem e de diferentes áreas da computação.

Os exemplos procuram demonstrar, de forma clara e objetiva, conceitos relacionados à manipulação de arquivos, processamento binário, automação, integração com aplicações externas e desenvolvimento de utilitários, sempre priorizando implementações simples, bem documentadas e voltadas ao ensino.
